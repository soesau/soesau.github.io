Surface Reconstruction from Range Data

#include <CGAL/Range_data_surface_reconstruction.h>

Definition

template<typename GeomTraits>
class CGAL::Range_data_surface_reconstruction< GeomTraits >

reconstructs a watertight surface from a point set with normals and scanline information.

Follows the method described in [1]. An adaptive triangulation is built from the input point set and a graph cut is performed to label tetrahedra as inside or outside the surface. The surface is then extracted as the boundary of the inside tetrahedra.

CGAL::Range_data_surface_reconstruction< GeomTraits >::Range_data_surface_reconstruction ( Point_set &  points)

creates a Range_data_surface_reconstruction object.

The points must have a property map for the scan angle and either a property map for the scan direction or a property map for the point source ID. If the point set does not have a normal property map, normals will be computed via CGAL::scanline_orient_normals(). The required property maps are automatically created via CGAL::read_LAS(). They are: 'scan_angle' with type float, 'scan_direction_flag' with type unsigned char, 'point_source_ID' with type unsigned short.

Parameters
pointsa point set with normals and scanline information.

void CGAL::Range_data_surface_reconstruction< GeomTraits >::compute_features ( Parallel_tag  tag)

computes the local scale of the point cloud at each input point according to [2].

The eigenvectors and singular values of the covariance matrix of the local neighborhood are computed via SVD. The size of the local neighborhood is chosen to minimize the entropy. The point dimension is then determined by the relative magnitude of the singular values. The computed singular values are stored in the property map 'singular_values' with type std::array<double, 3> of the input point set. The computed eigenvectors are stored in the property map 'eigen_vectors' with type std::array<Vector_3, 3> of the input point set.

Parameters
tagthe concurrency tag to use for parallelization.

template<typename GeomTraits >
void CGAL::Range_data_surface_reconstruction< GeomTraits >::compute_mass_function ( unsigned int  num_samples,
const Point_set &  barycenters 
)

computes the mass function for each tetrahedron in the adaptive triangulation via Monte Carlo sampling.

Alternatively, the mass function values for each finite tetrahedron can be retrieved by looking up the barycenter of each tetrahedra in the parameter barycenters and using the provided property 'mass'.

Parameters
num_samplesthe number of Monte Carlo samples to draw for each tetrahedron in the adaptive triangulation. Defaults to 40. The computational effort scales linearly with the number of samples. The more samples are drawn, the more accurate the mass function values will be.
barycenterspoint_set containing the barycenters of all finite tetrahedra in the adaptive triangulation. A property 'mass' with type std::array<double, 3> must be present in the point_set. The mass function values for each tetrahedron will be set according to the values in the property 'mass' of the corresponding barycenter.
Precondition
compute_features() has been called and the adaptive triangulation has been created.
